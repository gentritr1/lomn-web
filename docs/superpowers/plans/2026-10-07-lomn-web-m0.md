# LOMN Web M0 (Foundations) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the reproducible foundation for porting *BIONICLE: The Legend of Mata Nui* to the web.
- A one-command decompilation pipeline (`make decomp`) that turns the player's own exe into an original-layout corpus, headers, a work queue and surface/census reports.
- An engine skeleton (file system, render interface with null + WebGPU backends, deterministic loop) that builds natively and as wasm32.
- A layered test harness (`make check`) proven on real hardware.

**Architecture:**
- Python tools wrap Ghidra 12.1.4 headless plus our own CodeView NB11 reader.
- Everything derived from LEGO's binary is written to `gen/` (gitignored), never committed.
- The C++17 engine uses `webgpu.h` (Dawn natively, emdawnwebgpu in the browser) behind a small `rhi.h`.
- The loop replays the original `ScProcessManager` fake-delta step (`0.006666666828095913`).

**Tech Stack:** Python 3.14 + pytest 9.0.3/Pillow 12.3.0/NumPy 2.5.3 · Ghidra 12.1.4 (JDK 21) · CMake ≥ 3.28 + Ninja · Apple clang (native) · emsdk 6.0.11 · Dawn / emdawnwebgpu v20261002.154047 · doctest 2.5.3 · stb_image_write · Node ≥ 23 + Playwright 1.63.0 (Chromium).

**Spec:** `docs/superpowers/specs/2026-10-07-lomn-web-port-design.md` (M0a + M0b, §8). Read it first.

**Reference bundle:** `docs/superpowers/plans/2026-10-07-m0-ref/` mirrors the repo layout. Every file in it was built and run on 2026-10-07 against the real game data, with the results quoted in each task.
- A step that says *"Create `X` with the content of `REF/X`"* means copy that file byte for byte. `REF` = `docs/superpowers/plans/2026-10-07-m0-ref`.

## Global Constraints

- **Never commit game data or anything derived from LEGO's binary.**
  - `*.exe`, `*.dll`, `*.blk`, `*.bik`, `gen/`, `.env.local`, `.toolchain/`, `build/` stay gitignored.
  - Committed: our code, tools, reports containing only names and counts (`docs/surface.md`, `docs/census.md`, `docs/dashboard.html`), and `worklist/status.json`.
- **Never run `LEGOBionicle.exe`** or any original binary. Only parse it as data (nb11, Ghidra). Original-game runs are user-launched.
- `$LOMN_DATA` layout:
  - `reference/LEGOBionicle.exe` (SHA-256 `09b55e62f78824607e31433ddfcea827ec836523afd8de3fcc9f3f3f4ec70f0f`)
  - `install/` (Beta 1.5.0; its exe SHA-256 is `b372afb9cb4bbae338a0368dc15cff6bdf49f996148fe80f4e15cfa4869b3ab8`)
- **Tests that need game data** skip with the reason `SKIPPED (no LOMN_DATA)`. Tests that need `make decomp` output skip with `SKIPPED (run make decomp first)`. C++ tests that can't run return 77 (ctest `SKIP_RETURN_CODE`).
- **Pins** are exactly those in `REF/deps.lock`; no other versions.
- **Every external command** in scripts, Makefile and tests carries an explicit timeout. **Never use fixed sleeps** to wait for state.
- **Browser tests** use Playwright `channel: 'chromium'` + `--enable-unsafe-webgpu`. They always check pixels, never only a state flag. The default headless shell falls back to SwiftShader, whose canvas screenshots come out blank while state reads `drawn` (measured 2026-10-07).
- **Performance numbers** are always printed with frame-count reconciliation. **No threshold is set before a measurement exists.**
- **Implementers are Claude subagents; the controller owns git.**
  - Each task ends with one commit whose message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  - Do not push.
- **Platform:** macOS arm64 (the dev machine). Linux/Windows support is out of scope for M0.

## Review Focus

1. **`$LOMN_DATA` points at a REBUILT or unknown exe** → `make check-data` must name the problem ("unknown build", with the sha256) and exit non-zero, never continue with wrong offsets. Pinned by `test_unknown_install_build_rejected` (Task 1).
2. **Game paths come in Windows form with mixed case** (`Root\DATA\levels\LEV1\nUju.blk`) → must resolve on case-sensitive file systems and in memory. Pinned by `test_fs.cpp` "disk fs: case-insensitive Root lookup" and the normalize cases (Task 6).
3. **Ghidra analysis or a script fails partway** (bad JDK, script compile error, timeout) → `make decomp` must stop with the log path, not produce a partial `gen/` that later tests treat as valid. Pinned by the `REPORT SCRIPT ERROR` / `Script compile failed` check in `run_decomp.ghidra()` and the Task 4 negative step (break a script, expect exit ≠ 0).
4. **A test passes natively but not as wasm32, or traces drift between them** → a failure. Pinned by `make test-wasm`, which runs ctest under Node *and* byte-compares native vs wasm32 `trace.jsonl`/`calls.txt` (Task 7).
5. **The browser silently renders nothing** (no adapter, SwiftShader, wrong canvas) while the state flag looks healthy → the smoke test must fail on pixels. Pinned by `smoke.mjs` centre/corner pixel checks and the empty-site negative run (Task 8).
