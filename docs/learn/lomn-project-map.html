If you set up a new Mac

  1. Clone the private repo from GitHub.
  2. Download the game beta 1.5.0 from the LOMN-Beta release. Unpack SetupBeta.exe with 7-Zip. Do not run it.
  3. Point .env.local (LOMN_DATA) at a folder with an install link to the game copy.
  4. Run the toolchain setup in the repo. It downloads Emscripten and Dawn again.
  5. Rebuild gen/ with Ghidra and tools/decomp, following docs/knowledge/reverse-engineering-playbook.md.
  6. Open docs/resume/README.md and continue.
